Kosakata Keluarga
家族 (kazoku)

Bahasa Jepang punya dua set kata untuk anggota keluarga: satu untuk keluarga sendiri (merendah), satu untuk keluarga orang lain (menghormati). Salah pakai terdengar aneh — ini yang sering membingungkan pembelajar.

Aturan Inti

⚖️ Dua set kata

Ini konsep terpenting dalam kosakata keluarga Jepang.

Keluarga SENDIRI (merendah)

Dipakai saat bicara tentang keluarga sendiri kepada orang lain.

  • 父 (chichi) — ayah saya
  • 母 (haha) — ibu saya

Contoh: 父は先生です。 = Ayah saya guru.

Keluarga ORANG LAIN (hormat)

Dipakai untuk keluarga orang lain — juga saat memanggil keluarga sendiri langsung.

  • お父さん (otousan) — ayah (Anda/beliau)
  • お母さん (okaasan) — ibu (Anda/beliau)

Contoh: お父さんは何歳ですか。 = Ayah Anda berumur berapa?
