Menulis Wacana Formal 文章の書き方

💡 Tulisan formal Jepang berbeda dari percakapan sehari-hari. Gunakan だ・である体 (bukan です・ます体) untuk esai dan laporan akademik.

📝 Struktur Esai Standar (段落構成)

BagianIsiEkspresi Kunci
序論(じょろん)
Pendahuluan		Latar belakang + pernyataan masalah + thesis〜が問題となっている / 本稿では〜を論じる / 〜について考察する
本論(ほんろん)
Isi Utama		Argumen + bukti + analisisまず〜 / 次に〜 / さらに〜 / 一方〜 / これに対し〜
結論(けつろん)
Kesimpulan		Ringkasan + implikasi + penutup以上を踏まえると〜 / 本稿で論じたように〜 / 今後の課題として〜
