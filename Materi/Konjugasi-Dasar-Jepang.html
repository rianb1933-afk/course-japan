Tata Bahasa Inti N5-N4

Konjugasi Dasar
Bahasa Jepang

Konjugasi adalah mesin utama grammar Jepang. Kuasai bentuk sopan, negatif, te-form, ta-form, potential, dan kata sifat agar pola N4-N3 terasa jauh lebih mudah.

Pengelompokan Kata Kerja

Mengenal Kelompok Kata Kerja

Sebelum mengubah bentuk, tentukan dulu kelompok katanya. Ini mencegah salah te-form dan nai-form.

KelompokCiriContohCatatan
る-verbSering berakhir える atau いる食べる, 見る, 起きるBuang る, tambah bentuk baru.
う-verbAkhir kata berubah mengikuti baris kana飲む, 書く, 話す, 行くPerubahan tergantung akhiran.
Tidak BeraturanHafalkan khususする, 来る勉強する mengikuti pola する.
Tidak semua kata berakhir る adalah る-verb. Contoh penting: 帰る, 入る, 走る adalah う-verb.
Bentuk Inti

Bentuk yang wajib otomatis

Bentuk ini muncul terus di latihan grammar, reading, listening, dan percakapan.

Bentukる-verbう-verbTidak BeraturanFungsi
ます食べます飲みますします / 来ますSopan sekarang/kebiasaan.
ません食べません飲みませんしません / 来ませんNegatif sopan.
ました食べました飲みましたしました / 来ましたLampau sopan.
ない食べない飲まないしない / 来ないNegatif plain.
て食べて飲んでして / 来てPermintaan, sambungan, sedang.
た食べた飲んだした / 来たLampau plain, pengalaman.
potential食べられる飲めるできる / 来られるKemampuan.
Peta Te-form

Pola te-form untuk う-verb

Bagian ini perlu hafalan pola bunyi. Latih sampai otomatis.

う・つ・る → って

買う → 買って待つ → 待って帰る → 帰って

む・ぶ・ぬ → んで

飲む → 飲んで遊ぶ → 遊んで死ぬ → 死んで

く・ぐ・す

  • 書く → 書いて
  • 泳ぐ → 泳いで
  • 話す → 話して
  • Pengecualian: 行く → 行って
Kata Sifat

Konjugasi kata sifat

Kata sifat Jepang juga berubah bentuk. Pisahkan i-adjective dan na-adjective.

JenisSekarangNegatifLampauLampau Negatif
い-adjective高いです高くないです高かったです高くなかったです
な-adjective静かです静かではありません静かでした静かではありませんでした
Exceptionいいですよくないですよかったですよくなかったです
Penggunaan

Pola penggunaan penting

Setelah bentuknya bisa dibuat, pakai dalam pola kalimat nyata.

てください

  • 読んでください。
  • Tolong baca.
  • Lebih sopan dari perintah langsung.

ています

  • 今、勉強しています。
  • Sedang belajar sekarang.
  • Juga bisa menyatakan keadaan: 結婚しています.

たことがある

  • 日本へ行ったことがあります。
  • Pernah pergi ke Jepang.
  • Gunakan ta-form sebelum pola ini.
Latihan

Latihan konversi cepat

Ubah tiap kata ke bentuk yang diminta, lalu buat satu kalimat pendek.

Kata Kerja

  • 食べる → ます, ない, て, た
  • 飲む → ます, ない, て, た
  • 書く → ます, ない, て, た
  • 行く → ます, ない, て, た

Kata Sifat

  • 高い → negatif, lampau
  • 楽しい → negatif, lampau
  • 静か → negatif, lampau
  • 便利 → negatif, lampau

Checklist Naik Level

  • Bisa mengenali る/う/irregular.
  • Bisa membuat te-form tanpa melihat tabel.
  • Bisa membedakan ない dan ません.
  • Bisa membuat kalimat てください, ています, たことがある.
Bentuk Biasa

Bentuk Biasa (Plain Form) — た-form & ない-form

Selain te-form, bentuk た dan ない adalah pondasi puluhan pola grammar. Kuasai konversi ini secara otomatis.

Bentukる-verbう-verb (む・ぶ・ぬ)う-verb (く・ぐ)う-verb (す)Tidak Beraturan
た-form (past)食べた飲んだ / 遊んだ書いた / 泳いだ話したした / 来た
ない-form (neg)食べない飲まない書かない話さないしない / 来ない
Dictionary form食べる飲む書く話すする / 来る
Pengecualian penting: 行く → 行って (bukan 行いて). ある → ない (bukan あらない).
Kata Sifat

Konjugasi い-adjective & な-adjective

Kata sifat Jepang juga berkonjugasi untuk waktu, negasi, dan menghubungkan kalimat.

Bentukい-adj (contoh: 大きい)な-adj (contoh: 元気)
Positif sekarang大きいです元気です
Negatif sekarang大きくないです / 大きくありません元気じゃないです / 元気ではありません
Positif lampau大きかったです元気でした
Negatif lampau大きくなかったです元気じゃなかったです
Menghubungkan (て-form)大きくて元気で
Adverbia (て-form)大きく + verb (contoh: 大きく書く)元気に + verb (contoh: 元気に働く)
Latihan Cepat

10 Kata Kerja — Konversi Semua Bentuk

Latih setiap kata kerja ke bentuk て・た・ない・ます. Waktu target: 2 menit.

Set 1 — る-verb

  • 食べる → て: 食べて / た: 食べた / ない: 食べない
  • 見る → て: 見て / た: 見た / ない: 見ない
  • 起きる → て: 起きて / た: 起きた / ない: 起きない
  • 寝る → て: 寝て / た: 寝た / ない: 寝ない

Set 2 — う-verb

  • 飲む → て: 飲んで / た: 飲んだ / ない: 飲まない
  • 書く → て: 書いて / た: 書いた / ない: 書かない
  • 話す → て: 話して / た: 話した / ない: 話さない
  • 行く → て: 行って ⚠️ / た: 行った / ない: 行かない

Set 3 — う-verb lanjutan

  • 待つ → て: 待って / た: 待った / ない: 待たない
  • 帰る → て: 帰って / た: 帰った / ない: 帰らない
  • 買う → て: 買って / た: 買った / ない: 買わない
  • する → て: して / た: した / ない: しない
